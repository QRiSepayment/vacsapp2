Dashboard, Command Center, dan Report membaca data dari ACCESS_EVENTS (bukan hanya ACCESS_LOG). Menghapus baris di Spreadsheet tab ACCESS_LOG saja TIDAK cukup — data lama tetap muncul di aplikasi selama masih ada di ACCESS_EVENTS. Gunakan form ini untuk menghapus permanen data pada rentang tanggal tertentu dari ACCESS_EVENTS. Aksi ini permanen dan tidak bisa dibatalkan.
